🛠️ Làm thế nào để sử dụng file Bookmark?

1
⬇️

Nhấn nút 'Xuất file' ở trên để tải file .html về máy.

2
📂

Mở trình quản lý Bookmark trên trình duyệt (nhấn Ctrl+Shift+O hoặc Cmd+Option+B).

3
📥

Chọn 'Import Bookmarks' (Nhập dấu trang) và chọn file vừa tải về.
